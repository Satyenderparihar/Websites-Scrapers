## ⚡ Core Features

1. **Exact Official Website URLs**: Every tool is linked directly to its official domain (e.g. `gamma.app`, `vocalremover.org`, `tinywow.com`). Zero Google search links.

2. **100% Strict Channel Isolation**: Every channel has its own dedicated directory (`📁 <ChannelName>/`) with pure, unmixed data.

3. **Zero Duplicates**: Normalized hashing ensures every tool is listed once with all its video occurrences.

4. **1-Click Auto GitHub Push**: Runs on every scrape, syncing fresh databases and reports directly to GitHub.

5. **Multi-Format Export**: Generates GitHub-flavored Markdown, styled Excel spreadsheets (`.xlsx`), and structured JSON.

## 🛠️ How to Run

1. Double click **`YouTube Websites Extractor.lnk`** on Desktop.

2. Press **Enter** to update default channel (`@setupsaitony`) OR paste any new channel URL.

3. The agent will scrape, categorize, format, and push to GitHub automatically in **1 Click**!
